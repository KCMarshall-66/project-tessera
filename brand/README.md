# Brand

Identity assets for Tessera.

- **[`index.html`](index.html)** — the brand page: every asset on a light and a dark surface, with what it is for and where it is used.
- [`logos/`](logos) — the logo and marks. See [`logos/README.md`](logos/README.md).
- [`ai-sparkle.svg`](ai-sparkle.svg) — the mark for anything Tessera AI does: the button in the corner of each dashboard card, and the chat's avatar. 16px, in the accent blue (`#689AE2`) so it works on light and dark surfaces. It lives here rather than in `logos/` because it is a product mark, not part of the logo.
