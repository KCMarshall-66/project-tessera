# Design System

Tessera's design system: color/typography/spacing tokens, core components, and UI patterns.

- **[`index.html`](index.html)** — the visual style guide: colour, type, spacing, the card, every component, the AI patterns, and motion, rendered from the app's own files.
- [`colors.md`](colors.md) — brand palette (seeded from [`../brand/logos/tessera-color-logo.png`](../brand/logos/tessera-color-logo.png)), status colours, product colour sets, and known contrast gaps.
- [`typography.md`](typography.md) — type scale and weight usage for IBM Plex Sans (ExtraLight/Regular/SemiBold).
- [`spacing.md`](spacing.md) — 8px-grid spacing scale, semantic aliases, and layout tokens.
- [`card.md`](card.md) — the faded card (stat cards and panels): gradient fill, side/bottom borders, bottom-only radius.
- [`components.md`](components.md) — every component in the prototype, where it is defined, and the rules it follows, including the AI patterns.

Brand assets are documented on their own page: [`../brand/index.html`](../brand/index.html).
